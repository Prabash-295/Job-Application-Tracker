## 📌 Overview

**Job Application Tracker** is a React-based web application designed to help users organize, manage, and track their job applications throughout different recruitment stages.

The application provides a centralized and responsive interface where users can add and manage job application records, search and filter applications, and track their application status efficiently.

---

## ✨ Features

* 🔹 Add and manage job application records
* 🔹 Track applications based on recruitment status
* 🔹 Search job applications efficiently
* 🔹 Filter applications based on relevant criteria
* 🔹 Form handling with input validation
* 🔹 Reusable React components for a modular structure
* 🔹 State management for dynamic application data
* 🔹 Responsive design for desktop and mobile devices

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### 1. Clone the repository

```bash
git clone https://github.com/Prabash-295/Job-Application-Tracker

```

### 2. Navigate to the project directory

```bash
cd Job-Application-Tracker

```

### 3. Install dependencies

```bash
npm install

```

### 4. Start the development server

```bash
npm run dev

```

The application will be available at:

http://localhost:5173

```

## 🧠 Key Implementation Details

* Built the application using **React.js** with a component-based architecture.
* Created reusable components to keep the application modular and maintainable.
* Used **React state management** to handle application data and UI updates.
* Implemented form handling for adding and managing job application records.
* Added **form validation** to improve data accuracy and user experience.
* Implemented **search functionality** to quickly find job applications.
* Implemented **filtering functionality** to organize and view relevant applications.
* Added **status-based application tracking** to monitor progress across different recruitment stages.
* Used JavaScript ES6+ features for cleaner and more efficient application logic.
* Designed a responsive interface using HTML and CSS.
